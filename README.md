### Projects
 
**[AutoBoard.ai](https://github.com/Phyboc/AutoBoard.ai)** &nbsp;`Agentic AI`
 
MCP server that turns any AI assistant (Claude, Cursor) into an HR & IT orchestration agent. Onboards and offboards employees across Google Workspace, Slack, GitHub, Jira, and AWS via a single natural-language command. 10+ tools, confirmation guards on destructive ops, live Nitrocloud deployment, React widgets rendered in chat.
 
`TypeScript` `Node.js` `MCP` `Zod` `Next.js` — *Amrita × Nitrostack Agentic AI Hackathon*

**[Legal Document Summarizer](https://github.com/Phyboc/Legal-Document-Summarizer)** &nbsp;`NLP`
 
Fine-tuned BART on the IN-Abs Indian Supreme Court dataset. Pipeline: TextRank pruning → hierarchical map-reduce for long inputs → cross-encoder Cite & Verify post-processing. Next.js frontend + FastAPI backend.
 
`Python` `HuggingFace` `BART` `FastAPI` `Next.js`

**[UI-Auditer](https://github.com/Phyboc/UI-Auditer)** &nbsp;`Developer Tool`
 
CLI that scores any webpage's UI (0–100) against five audience personas — Gen-Z, Elderly, Corporate, Minimalist, Neurodivergent. Uses Playwright to extract real computed styles from JS-rendered pages, not static HTML. Dealbreaker penalties, JSON output flag for CI pipelines.
 
`Python` `Playwright` `Click` `Rich`
