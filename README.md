**[UI-Auditer](https://github.com/Phyboc/UI-Auditer)** — CLI tool that scores any webpage's UI against five audience personas (Gen-Z, Elderly, Corporate, Minimalist, Neurodivergent). `Python` `Playwright` `Click` `Rich`

`Python` `HuggingFace` `BART` `FastAPI` `Next.js`

`Next.js` `React` `TypeScript`

`Java` `Algorithms`
